##### DEPENDENCIES  
ncurses  
iana timezone database  

##### INSTALL
build `make`  
install `doas make install`

##### KEYBINDS  
```
i			input chart data  
	F1		clear fields  
	tab		fill local time  
	arrows	navigate  
	\		draw chart
	esc		cancel
	
enter		animate chart  
	h/l 	time increment  
	k/j 	up/down  
	0...9	increment count

0...9		chart number
alt+0...9	synastry w/ chart
t			transits
s			solar return

tab			live update  

r			redraw chart  
[R]			redraw config chart

w			save chart  
	m		make dir  
	enter	choose dir
	esc		cancel  
	
e		 	load chart  
	l/enter	choose  
	esc		cancel  

j			write diary
	esc		save entry
	
[J]			read diary
	j/k		down/up line
	h/l		prev/next entry
	ctrl+e	scroll down
	ctrl+y	scroll up

z			zodiacal releasing
	k/j		up/down period
	h/l		up/down layer
	tab		switch lot
	
c			config
	tab		set current chart info to config
	enter	set config default
	space	toggle buttons
	esc		cancel
	
d			toggle DST
o 			toggle right table
p			toggle left table
	[P]		next page

q			exit astro  
```
